# Sangini Trading Terminal (Client)

A high-fidelity trading dashboard built for real-time portfolio tracking, virtual equity execution, and financial education.

## 📊 Core Functionalities
* **Live P&L Tracking:** Utilizing React **Context API**, the dashboard provides a "Live Heartbeat," updating Profit & Loss statements instantly as market prices fluctuate.
* **Portfolio Management:** Separated views for **Holdings** (long-term) and **Positions** (intra-day) to mirror professional trading platforms.
* **Interactive Financial Literacy Quiz:** A custom assessment module designed to educate users on market basics and risk management. It features instant feedback and scoring logic to ensure user readiness.
* **Dynamic Watchlist:** Real-time "Price Flashing" animations to notify users of market movements for equities like RARE and GLOSSIER.

## 🛠 Tech Stack
* **Frontend:** React.js (Hooks & Context API)
* **Data Visualization:** Chart.js (Interactive vertical equity distribution charts)
* **Styling:** Custom CSS3 with BEM architecture and keyframe animations
* **API Client:** Axios for asynchronous communication with the Sangini Engine

## 🚀 Getting Started
1. Clone the repository
2. Run `npm install`
3. Run `npm start` to view the terminal on `localhost:3000`
